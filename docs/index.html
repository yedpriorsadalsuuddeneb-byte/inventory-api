Inventory API

Reference for the item lookup and order total endpoints.

Endpoints

MethodPathDescription
GET/itemsList all items.
GET/items/<id>Get one item. Unknown ids return null with status 200.
GET/items/<id>/total?quantity=NOrder total for N units of an item.

Pricing rules

  • Total = price x quantity, rounded to 2 decimals.
  • A 10% bulk discount applies to orders of more than 10 units.

Example

GET /items/2/total?quantity=10
{"id": 2, "quantity": 10, "total": 108.0}
